加密市场周度决策简报 | 2026.07.06 - 2026.07.12

一、本周核心结论

  • 资金主线：ETF 与 DeFi 流动性仍是核心变量，价格表现有修复，但资金尚未扩散到全面山寨行情。
  • 重要新闻：Swift 银行链上结算、BlackRock BUIDL 扩张、SpaceX 私募股权代币化交易共同强化 RWA / 机构基础设施主线。
  • 市场情绪：BTC 仍以防守资产身份承接资金，山寨反弹选择性明显，说明市场更偏结构性机会而不是全面风险偏好回升。
  • 一级项目：机构融资和基础设施融资优先级高于零散任务型空投；需要看融资金额、领投机构和产品落地路径。
  • 交易所与机构风向：Vanguard、Sony、EDX Markets 等传统机构线索显示，合规入口仍在扩张。
  • 核心代币：BTC 稳住主线，ETH / SOL 可跟踪修复强度，RWA 和稳定币相关资产仍是中期观察方向。

来源：OriginBrief 7月13日周报、Coinposters 7月13日市场周报｜置信度：中

二、加密大事件

  • Swift 推进 17 家银行参与的区块链结算网络，表明银行级链上结算不再停留在概念层。
  • BlackRock BUIDL 规模继续扩大，RWA 从债券、基金延伸到更广泛的金融资产。
  • Circle 和 Sony 稳定币信托银行线索强化合规稳定币通道，但这属于中长期制度建设，不是短线行情催化。
  • Polymarket 寻求更深监管路径，预测市场从流量产品向可监管交易基础设施演进。
  • DeFi 安全事件继续出现，Summer.fi、Hedera / Bonzo 等漏洞说明机构资产上链后，风险面同步扩大。

来源：OriginBrief 7月13日周报｜置信度：中

三、一级打新 / 空投 / 融资项目

  • 本周主要机构风向集中在稳定币结算、AI Agent 支付、链上信用和 RWA 基础设施。
  • EDX Markets 融资、AI Agent 结算相关联盟、BNB Chain AI Agent L1 规划均属于机构风向，不直接等于可参与机会。
  • 观察标准：融资金额大、头部机构领投或赛道具备明确风向意义时进入一级资金风向；无明确参与入口不进入重点项目。

来源：OriginBrief 7月13日周报｜置信度：中
